# MT6835磁编码器

面向 RM25 赛季工程机器人自定义控制器的磁编码器模块。采用 MT6835 角度编码器和 STM32F103 主控，板载 CAN 收发器，用于向外部主控传输角度信息。原项目说明支持 5V 输入，安装孔位适配大疆 3508 电机。

## 一、主要功能与硬件组成

| 项目 | 配置或用途 |
| --- | --- |
| 角度采集 | MT6835 |
| 主控 | STM32F103 |
| 对外通信 | CAN |
| 供电 | 原项目标注 5V 输入 |

### 原理图器件与连接器索引

| 位号 | 工程标注 |
| --- | --- |
| U12 | MT6835GT-STD，角度传感器 |
| U13 | STM32F103C8T6，主控 |
| U8 | MAX3051EKA+T，CAN收发器 |
| U3 | AMS1117S-3.3，稳压器 |
| CN5、CN6 | GH125-S04DCA-00，4Pin连接器 |
| CN12 | HDGC1251WR-S-4P，4Pin连接器 |

CN5、CN6 和 CN12 虽均为4Pin连接器，不能据此认定针序和用途相同。供电、CAN、下载及调试信号必须按原理图逐针核对。角度零位、方向、滤波和CAN报文由固件决定，当前硬件仓库未收录原网页的编码器代码附件。

## 三、复刻与使用

1. 导入工程，核对原理图、PCB版本、器件型号和封装。
2. 按原理图针号核对供电极性、信号电平及连接器插接方向；不要仅依赖线色或照片判断针序。
3. 制板前执行电气规则与PCB设计规则检查，复核板框、孔位和制造参数。
4. 焊接后先检查短路与器件方向，确认电源正常后再连接外部设备并逐项验证功能。

安装前核对磁铁、轴心与传感器的相对位置；CAN通信需要结合固件核对波特率、报文格式、节点标识和终端电阻。硬件工程不等同于已配置完成的控制系统。
